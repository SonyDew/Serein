# Serein 0.1.0-beta.1 — Beta 1

English · Русский · Deutsch

**First public beta. Bugs and missing features are expected.**

## Start

Extract all files from the ZIP into one folder. Open `Serein.Gaming.WinUI.exe`.
Keep the other files beside it. No separate .NET installation is needed.
Tested on Windows 11 x64; Windows 10 has not been validated. This build is unsigned.

English is the default. Choose Russian or German in **Settings → App language**.

Start with monitoring. For gaming, select a game and choose background apps you
can safely pause. Gaming lowers their priority; Extreme freezes them temporarily.
Freezing stops downloads and file saves and can hold shared resources. Use
**Restore all** to undo Serein's temporary changes. Recovery cannot cover every failure.

Driver discovery installs nothing. Windows Update and manufacturer sites may have
different coverage. The app does not install firmware. Some hardware sensors need
separately installed supported AMD components and explicit permission.

Tray, cleanup, startup/services, integrated FPS recording and the full driver
installer are not yet in this WinUI beta. There is no guaranteed FPS improvement.

## Русский

Полностью распакуйте архив и откройте `Serein.Gaming.WinUI.exe`. Русский язык:
**Settings → App language → Русский**. Это первая бета, возможны ошибки.
Начните с мониторинга. Замораживайте только приложения, которые можно поставить
на паузу. «Восстановить всё» отменяет временные изменения Serein.

## Deutsch

Entpacke das ganze ZIP und öffne `Serein.Gaming.WinUI.exe`. Deutsch auswählen:
**Settings → App language → Deutsch**. Das ist die erste Beta; Fehler sind möglich.
Beginne mit der Überwachung. Friere nur Apps ein, die du sicher pausieren kannst.
**Alles zurücksetzen** macht vorübergehende Serein-Änderungen rückgängig.
