# Serein — Beta 1.1

Added a game picker for installed **Steam, Epic Games and GOG** games, with search
and store filters. You can still choose your own EXE. If several executables are
found, choose the actual game process. Selecting a game does not start it or enable
gaming mode.

Automatic discovery does not cover every launcher or protected Store game; use
Custom EXE where accessible.

Download **Serein-0.1.0-beta.1.1-win-x64.zip**, extract all files and open
**Serein.Gaming.WinUI.exe**. This is still a beta, tested on Windows 11 x64 and
unsigned. Feedback and suggestions are welcome.

Русский: добавлен выбор установленных игр из Steam, Epic Games и GOG, поиск и
фильтр по магазину. Возможность указать свой EXE сохранена.

Deutsch: Spiele aus Steam, Epic Games und GOG auswählen, suchen und nach Store
filtern. Eine eigene EXE kann weiterhin gewählt werden.
