# Serein 0.1.0-beta.1 — first public beta

Welcome to the first public test version. Feedback, bug reports, translations and
suggestions for improvements or new features are very welcome.

## Download and start

Choose **Serein-0.1.0-beta.1-win-x64.zip**, extract every file and open
**Serein.Gaming.WinUI.exe**. Keep the folder together. .NET/Windows App SDK runtimes
are included; AMD components are not. This executable is unsigned.
**SHA256SUMS.txt** contains the archive checksum.

Tested on Windows 11 x64. Windows 10, mixed DPI and the complete accessibility
matrix have not been validated. This is a portable folder, not an installer.

## Included

- Native WinUI 3 dashboard with real CPU/GPU/RAM activity, charts and hardware summary.
- Explicit Gaming/Extreme sessions for approved apps, temporary manual process
  actions and a separate restoration watchdog.
- Device categories, CPU summaries, SSD model/capacity/firmware, curated recognition
  and relevant official support without motherboard fallback.
- Explicit Windows Update driver discovery; installation handed to Windows Settings.
- Themes, custom accents/layout, optional Liquid Glass, original bundled images,
  local image import and optional animated vector patterns.
- English by default; Russian and German selectable immediately in Settings.

## Limits

No guaranteed FPS gain. Freezing pauses file saves/downloads and can hold shared
resources. Restoration cannot cover every failure. Choose only apps you can safely
pause and use Restore all when needed.

Driver search is not a universal latest-driver catalog. Unknown devices remain
unknown. Support links are not confirmed newer/compatible packages. No firmware
installer. AMD sensors depend on supported installed components; CPU connection is
explicit and may need administrator permission.

Tray, cleanup, startup/services, integrated FPS capture and the full in-app driver
installer are not yet in this interface. Legacy WPF source is included for development;
its extra features are not part of this beta executable.

## Verification

122 experiment checks, 132 native UI checks and 58 Core regression checks passed
on the Windows 11 test host. This includes real language-picker events and isolated
test-owned freeze/priority/restore scenarios. One earlier fixture run was refused
by conservative eligibility checks; a subsequent complete run passed. No protection
was bypassed. These tests do not establish compatibility with every PC or game.
