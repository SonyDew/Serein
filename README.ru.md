# Serein

**Помощник для игрового ПК на Windows. Бета 1.1 — 0.1.0-beta.1.1.**

[English](README.md) · [Русский](README.ru.md) · [Deutsch](README.de.md)

**Новое в Beta 1.1:** выбор установленных игр Steam, Epic Games и
GOG с поиском и фильтром по магазину. Свой EXE тоже можно выбрать. Если у игры
несколько EXE, нужно указать игровой процесс.

Serein показывает нагрузку на компьютер и позволяет временно управлять выбранными
фоновыми приложениями во время игры. Ещё программа помогает разобраться в устройствах
и найти официальную поддержку драйверов. Обещаний прироста FPS нет: результат зависит
от компьютера, игры и фоновых задач.

## Как запустить

1. Откройте [Releases](https://github.com/SonyDew/Serein/releases).
2. В **Assets** скачайте **Serein-0.1.0-beta.1.1-win-x64.zip**. Архивы Source code
   предназначены для самостоятельной сборки.
3. Полностью распакуйте ZIP в папку. EXE должен оставаться рядом с остальными файлами.
4. Запустите **Serein.Gaming.WinUI.exe**. Отдельно устанавливать .NET не требуется.

Проверялась **Windows 11 x64**. Поддержка Windows 10 пока не проверена.
Сборка без цифровой подписи: Windows может сообщить о неизвестном издателе.
В релизе есть контрольная сумма SHA-256 для проверки архива.

## Что работает

- Нагрузка CPU/GPU/памяти, графики, активность диска и сети. Недоступные показания
  не подменяются выдуманными числами.
- Выбор игры и разрешённых фоновых приложений. Игровой режим снижает их приоритет,
  «Экстрим» временно замораживает.
- **«Восстановить всё»**, восстановление после игры и по таймеру, отдельный процесс
  контроля восстановления. Системные и игровые зависимости защищены.
- Ручное управление подходящими процессами.
- Сведения об устройствах, драйверах и прошивках SSD, поиск Windows Update,
  релевантные официальные сайты производителей.
- Темы, свои цвета, размер текста, форма панелей, блоки главного экрана, изображения
  и необязательные анимированные узоры Liquid Glass.
- **Английский, русский и немецкий.** По умолчанию английский. Язык меняется
  в **Settings → App language**, перезапуск не нужен.

## Ограничения беты

Это тестовая версия, возможны ошибки. Начните с мониторинга. Замораживайте
только приложения, которые можно спокойно поставить на паузу: остановятся загрузки
и сохранение файлов, возможны блокировки общих ресурсов. Восстановление проверено,
но не гарантируется при любом сбое Windows или компьютера.

Поиск драйверов ничего не устанавливает. Для установки открываются параметры Windows,
где вы сами выбираете действие. Пустой результат не означает, что все драйверы самые
новые. Каталог распознавания ограничен. Прошивки SSD программа не устанавливает.

Датчики AMD GPU используют существующий поддерживаемый драйвер. Температуре CPU нужен
отдельный поддерживаемый компонент AMD и явное подключение с правами администратора.
Компоненты AMD не включены в архив. На другом оборудовании показаний может быть меньше.

В релизе интерфейс **WinUI 3**. Трей, очистка, автозагрузка/службы, встроенный замер
FPS и полный установщик драйверов ещё не перенесены. Старый WPF-код сохранён для
разработки; его дополнительные функции не входят в возможности этого EXE.

## Сборка исходников

Нужны .NET 10 SDK, Windows SDK и инструменты Windows/WinUI из Visual Studio.
В PowerShell в папке проекта:

```powershell
powershell -NoProfile -File experiments/Serein.Gaming.WinUI/build.ps1 -Test
```

Программа появится в `artifacts/Serein-Gaming-WinUI/`.
Подробности: [описание беты](docs/releases/v0.1.0-beta.1.1.md).
